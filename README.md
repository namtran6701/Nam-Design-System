# Nam Design System

Your personal React design collection: save source code, push to GitHub, browse live previews, and install a design into another app.

## Run locally

Requires Node.js 22.12 or newer.

```bash
npm ci
npm run registry:build
npm run dev
```

Open the URL printed in the terminal. `npm run build` generates the installable registry, checks TypeScript, and builds the website. `npm run preview` serves the production build locally.

## Where to add designs

- `registry/`: reusable React source files. These exact components render in the gallery and are distributed to your apps.
- `registry.json`: names, descriptions, source files, and dependencies.
- `src/App.tsx`: gallery and `previews` map with interactive examples.
- `src/styles.css`: gallery appearance; these styles are NOT shipped with components.
- `public/r/`: generated installable JSON; regenerated by `npm run registry:build`.

### Add your own component

1. Save `registry/my-card.tsx` with a named React export. Use Tailwind classes or declare and ship all CSS dependencies. Interactive Next.js-compatible components should start with `'use client'`.
2. Add this entry to the `items` array in `registry.json`:

```json
{
  "name": "my-card",
  "type": "registry:block",
  "title": "My card",
  "description": "Describe when you would use it.",
  "files": [{ "path": "registry/my-card.tsx", "type": "registry:component" }]
}
```

3. Import `MyCard` in `src/App.tsx` and add `'my-card': <MyCard />` to `previews`. The gallery listing and source viewer read the catalog automatically.
4. Add external npm packages in `dependencies` in the registry entry, e.g. `"dependencies": ["lucide-react"]`. Include every local file the component imports. For other registry items, use `registryDependencies` with a full published registry item URL (a bare name refers to the upstream shadcn registry).
5. Run `npm run build`, check the preview, then commit and push:

```bash
git add .
git commit -m "Add my card"
git push
```

Use props for app-specific text, data, and callbacks. The included examples use ordinary Tailwind v4 colors and need no gallery CSS, fonts, or theme variables. Preview callback messages are demonstrations; connect callbacks to real app behavior after installation.

## Install in another app

Use a React + TypeScript + Tailwind project with shadcn initialized. Follow https://ui.shadcn.com/docs/installation for your framework. Then use the gallery's **View design → Copy install command** button, or:

```bash
npx shadcn@latest add https://namtran6701.github.io/Nam-Design-System/r/profile-card.json
```

Import `ProfileCard` from the installed location printed by the CLI (normally your configured components directory):

```tsx
import { ProfileCard } from "@/components/profile-card";

<ProfileCard
  name="Nam Tran"
  initials="NT"
  role="Designer & builder"
  onContact={() => window.location.assign("/contact")}
/>;
```

Installation copies source into your app. Updates are intentional, not automatic; review your changes before reinstalling an item. During local development, gallery commands use localhost and only work while the server is running on the same machine.

## Publish automatically with GitHub Pages

In repository **Settings → Pages → Build and deployment**, choose **GitHub Actions** as the source. The included workflow builds on every push to `main`, then publishes `dist/`. Pull requests only run the build.

Gallery: https://namtran6701.github.io/Nam-Design-System/

The site and component source served by Pages are public. No paid Figma plan, database, or API key is needed. The relative Vite base also supports other static hosts: build with `npm run build` and publish `dist`.
